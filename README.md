# SentinelML

SentinelML is an AI-powered ransomware detection and threat monitoring application.

## SentinelML V2

A Windows desktop security application featuring:

- 19-feature behavioral analysis
- Random Forest machine learning detection
- Filesystem entropy analysis
- SentinelGuard monitoring
- SentinelAI explanations
- Incident reporting
- Cybersecurity education

The Windows installer is distributed through GitHub Releases.
